# 🐍 貪食蛇 Snake Game

一個經典的貪食蛇小遊戲，使用純 HTML + CSS + JavaScript 製作，無需任何依賴。

---

## 🎮 如何遊玩

1. 直接雙擊 **`snake.html`** 在瀏覽器中打開
2. 遊戲會自動開始

### 控制方式

| 操作 | 按鍵 |
|------|------|
| 移動 ↑ | `↑` 方向鍵 |
| 移動 ↓ | `↓` 方向鍵 |
| 移動 ← | `←` 方向鍵 |
| 移動 → | `→` 方向鍵 |
| 暫停 / 繼續 | `空白鍵` 或 `P` 鍵 |
| 重新開始 | 點擊「重新開始」按鈕 |

### 規則

- 控制蛇頭移動，吃到黃色食物可增長身體並獲得 1 分
- 蛇頭撞到牆壁或撞到自己身體則 **Game Over**
- 分數越高，挑戰越大
- 最高分會自動儲存在瀏覽器中
